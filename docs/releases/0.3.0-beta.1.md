OpenBricks now includes parameterized notebooks, dependency workflows, live run activity, exact Git releases and wheel environments, project roles, and a compute-backed data workspace.

- Typed parameters and widgets, run overrides, per-step timeouts, DAG repair, and explicit safe retry policies.
- Streamed logs, progress/resource measurements, cancellation state, and durable webhook/SMTP notifications.
- Immutable Git commit snapshots, hashed wheel environments, release comparison, and captured-source reruns.
- SQL explorer, saved queries/history/charts, SQL Server JDBC ingestion and checkpoints, quality reports, lineage, and Delta history/time travel/restore/vacuum.
- Project membership and selected credential dispatch, CodeMirror editing, tabs, formatting, and notebook revisions.
- Resource visibility, output retention, streamed optional-encryption backups, validated restore with restart, and versioned Docker image publishing.

Management and compute remain separate containers with default 1 GiB and 4 GiB limits. Existing shared workspace data is migrated into the default project. Back up before upgrading; restore is an idle-workspace maintenance operation and restarts the management service. Backups cover the management volume, not remote SQL/S3/catalog services.

This is a beta for trusted teams. Project permissions do not isolate arbitrary Python code from the compute service account. Recorded lineage covers the instrumented data helpers. Exact reruns preserve source and wheel identity, not external database contents. The test suite includes real Spark/Delta and controller-to-compute execution; a live SQL Server round trip requires deployment-specific credentials.

Images: `ghcr.io/dylanbarber/openbricks:0.3.0-beta.1` and `ghcr.io/dylanbarber/openbricks-compute:0.3.0-beta.1` (Linux amd64). Portable Docker image archives and SHA-256 checksums are attached for installation without registry credentials, along with a deployment bundle including the optional catalog configuration. See the repository's deployment and upgrade instructions.
